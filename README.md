
# 🌈 Feira LGBTQIA+ — Plataforma de Visibilidade para Empreendedores

Este projeto tem como objetivo criar um espaço digital inclusivo para promover, apoiar e conectar empreendedores LGBTQIA+ de diferentes regiões e segmentos. A iniciativa visa impulsionar a visibilidade de pequenos negócios da comunidade, fortalecendo redes de apoio e ampliando a inclusão produtiva.

---

## 🧠 Objetivo Social Relevante

- Criar um espaço digital para **visibilidade e conexão** de empreendedores LGBTQIA+.
- Incentivar o **networking inclusivo** e o **apoio mútuo** dentro da comunidade.
- Alinhado ao **ODS 10 – Redução das Desigualdades** da ONU.

---

## ⚙ Tecnologias Utilizadas

- **Frontend**: HTML, CSS e React (via CDN + Babel)
- **Backend**: Flask com API REST
- **Banco de Dados**: Firebase Firestore (NoSQL, em nuvem)
- **Estilo Visual**: Gradiente com cores da bandeira LGBTQIA+, layout responsivo e moderno

---

## 💡 Funcionalidades Implementadas

- 📋 **Listagem de empreendedores** em formato de catálogo com cartões visuais
- 🔍 **Filtros inteligentes por**:
  - Categoria do negócio (moda, gastronomia, tecnologia, etc.)
  - Localização (estado)
  - Identidade (gênero ou orientação)
- 📦 **Integração com Firestore**: backend Flask acessa dados em tempo real
- 🧾 **Modal com perfil completo do empreendedor**, incluindo imagem e descrição
- 💻 **Interface responsiva**, adaptada para dispositivos móveis

---

## 🌍 Impacto Social

- Apoia a **inclusão produtiva de minorias**
- Garante maior **visibilidade a pequenos negócios LGBTQIA+**
- Fortalece o **sentimento de pertencimento, autonomia e rede solidária**
